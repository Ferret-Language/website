Common commands:

```bash
ferret init
ferret get
ferret update
ferret sniff
ferret list
ferret remove <alias>
ferret clean
```

Install specific package spec:

```bash
ferret get github.com/user/pkg@^v1.2.0
```

Neighbor package example:

```toml
[dependencies]
shared = "../shared"
```
