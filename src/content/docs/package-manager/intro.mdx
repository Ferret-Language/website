Ferret uses a manifest file named `fer.ret` and lockfile `ferret.lock`.

Minimal manifest:

```toml
[package]
name = "myapp"
version = "0.0.1"
compiler = "<=0.0.3"
entry = "main.fer"

[dependencies]
```

Add dependencies (remote or neighbor path), then run:

```bash
ferret get
```
