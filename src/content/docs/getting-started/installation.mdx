## Install (recommended)

<Tabs>
  <TabItem label="Linux">
    ```bash
    curl -fsSL https://ferret-lang.vercel.app/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Arch">
    ```sh
    curl -fsSL https://ferret-lang.vercel.app/install-arch.sh | sh
    ```
  </TabItem>
  <TabItem label="Windows (CMD)">
    ```bat
    powershell -NoProfile -ExecutionPolicy Bypass -Command "irm -useb https://ferret-lang.vercel.app/install.ps1 | iex"
    ```
  </TabItem>
</Tabs>

:::note
The installer downloads a prebuilt release for your OS/arch into `~/.ferret` (Linux/macOS) or `%USERPROFILE%\.ferret` (Windows), and adds the `bin/` directory to your PATH. On Termux, the script builds from source and installs into `$PREFIX`.
You can change the location by setting `FERRET_INSTALL_DIR`. Set `FERRET_ADD_TO_PATH=0` to skip PATH changes.
:::

## Verify installation

```bash
ferret --version
```

## Build from source

If you want to build Ferret yourself, you need Go and a C compiler available on the machine.

```bash
git clone https://github.com/Ferret-Language/Ferret.git
cd Ferret/compiler
./build.sh
```

Windows:

```bat
cd compiler
build.bat
```

This produces a self-contained compiler bundle at `output/ferret`.

## Running Ferret programs

```bash
./output/ferret/bin/ferret run main.ferr
```

Or if `ferret` is already on your `PATH`:

```bash
ferret run main.ferr
```
